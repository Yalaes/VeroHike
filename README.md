# VeroHike

Application web mobile de suivi de randonnée à pied.

## Description

VeroHike permet d'enregistrer et de suivre ses randonnées.

L'application permet notamment de suivre :

- le nombre de pas
- la distance parcourue
- la durée de la randonnée
- la date et les horaires
- l'historique des randonnées

VeroHike est conçu pour fonctionner hors ligne et stocker les données localement.

## Technologies

- HTML
- CSS
- JavaScript
- IndexedDB

Aucune bibliothèque ou framework n'est utilisé.

## Fonctionnalités prévues

### MVP

- Accueil
- Démarrer une randonnée
- Mettre en pause une randonnée
- Reprendre une randonnée
- Arrêter une randonnée
- Compter les pas
- Calculer la distance
- Mesurer la durée
- Enregistrer une randonnée
- Consulter l'historique
- Paramètres
- Fonctionnement hors ligne

### À venir

- Carte et parcours
- Statistiques avancées

## Privacy

VeroHike does not use cookies.

VeroHike does not use tracking or analytics.

No personal data is collected or shared.
